# 时间冒险家首版验收清单

在每个功能阶段完成后，先在 Mac Safari 中逐项检查，再在真实 iPad 的横屏和竖屏各检查一次。构建成功或页面能打开不代表数据规则已经正确。

## 任务与计时

- [ ] `TASK-01` 新建、编辑、排序、拆分和改到明天的任务，在刷新页面后仍然存在。
- [ ] `TASK-02` 开始任务后离开页面一分钟，返回时计时包含离开的时间。
- [ ] `TASK-03` 暂停任务后等待，计时不再增加；继续后从累计时间接着走。
- [ ] `TASK-04` 强制关闭浏览器并重新打开，进行中的计时仍按开始时间恢复。
- [ ] `TASK-05` 完成时填写的实际用时与预计用时独立保存，成长页统计同步更新。
- [ ] `TASK-06` 拆分一个至少 10 分钟的任务后出现两段，第二段不能继续无限拆分。
- [ ] `TASK-07` 跳过或改期不会扣除已经获得的星能，也不会被显示成人格化失败。
- [ ] `TASK-08` 任务卡片和时间轴清楚显示科目；新建或编辑任务时可以手动修改科目。
- [ ] `TASK-09` 手动任务可以设置开始时间；与已排任务冲突时，其他任务按顺序向后顺延且不再次重叠。
- [ ] `TASK-10` 添加任务对话框可以用一个小按钮清空全部输入内容。
- [ ] `TASK-11` 预计 20 分钟的任务选择实际 5 分钟后，卡片和统计都显示实际 5 分钟。
- [ ] `TASK-12` 今日页可以按语文、数学、英语等科目筛选任务，筛选结果数量与卡片一致。
- [ ] `TASK-13` 科目筛选会同步更新“下一步”任务；顶部今日总进度仍统计全部任务。

## 星能账本

- [ ] `LEDGER-01` 完成任务只获得一次奖励；重复点击完成和刷新重试不会重复入账。
- [ ] `LEDGER-02` 顶部余额始终等于全部账本记录的金额之和。
- [ ] `LEDGER-03` 达到每日奖励上限后明确提示，余额不会超过约定上限继续增长。
- [ ] `LEDGER-04` 复盘第一次保存只发放一次奖励，之后编辑不重复发放。
- [ ] `LEDGER-05` 账本保留奖励、消费、退回和纠错的原始记录，不静默改写历史。
- [ ] `LEDGER-06` 功能开关关闭时，底部不出现奖励页，完成任务和复盘不新增星能记录，已有账本数据不被删除。

## 兑换与家长审批

- [ ] `REDEEM-01` 星能不足时不能申请，页面展示还差多少。
- [ ] `REDEEM-02` 提交申请后先扣款，重复提交不会重复扣款。
- [ ] `REDEEM-03` 家长拒绝时必须填写原因，星能只退回一次。
- [ ] `REDEEM-04` 家长批准后状态是“已批准，未兑现”，不会被当成已经使用。
- [ ] `REDEEM-05` 记录实际兑现后状态变为“已兑现”，审批时间与兑现时间都保留。
- [ ] `REDEEM-06` 每日/每周上限在刚好达到边界时生效，被拒绝或取消的申请不占额度。
- [ ] `REDEEM-07` 额外游戏时间达到家庭约定上限后，即使星能足够也不能继续申请。

## 家长入口与隐私

- [ ] `PARENT-01` 第一次进入家长区必须设置 4 至 6 位数字 PIN。
- [ ] `PARENT-02` 输入错误 PIN 不能进入家长区；离开并锁定后需要重新验证。
- [ ] `PARENT-03` 家长修改奖励价格或上限后，仅影响之后提交的申请。
- [ ] `PARENT-04` 规则修改会生成历史版本，已经获得的奖励不被追溯扣除。
- [ ] `PARENT-05` 私密复盘不在家长区出现；孩子勾选分享后才显示。
- [ ] `PARENT-06` 家长区可以开启和暂停奖励模块，刷新后开关状态保持；暂停时不删除历史星能和兑换记录。
- [ ] `PARENT-07` 六套主题可切换并在刷新后保持，包含清爽、明亮、想象、自然、科技和电玩风格。
- [ ] `PARENT-08` 首次设置 PIN 和再次输入 PIN 时，在密码框按回车都能直接进入家长区，不会关闭弹窗。
- [ ] `PARENT-09` 家长可以开关应用内提醒，并设置准时、提前 5、10 或 15 分钟提醒。

## 成长与空状态

- [ ] `GROW-01` 没有任何任务和账本记录时，不显示虚构的进度或趋势。
- [ ] `GROW-02` 近 7 天完成数、估时平均差、主动调整数与原始记录一致。
- [ ] `GROW-03` 跳过复盘不扣星能，也不影响已获得奖励。
- [ ] `GROW-04` 全应用不使用公开排名、红色失败警告或“懒惰”等人格标签。

- [ ] `IMPORT-01` 设置名字和学号后，再打开设置仍能看到标签，并可添加、删除或修改。
- [ ] `IMPORT-02` “今日作业、周末作业、昨日完成情况”能分别识别为任务或反馈。

- [ ] `IMPORT-04` 工作日任务自动排在放学后，跳过晚饭和已有时间任务。

- [ ] `IMPORT-07` 老师反馈只保留匹配名字或学号的句子，其他人的反馈被忽略并明确提示数量。
- [ ] `IMPORT-08` 表扬和老师批评内容出现在当天页面，不改变星能余额，也不产生扣分。
- [ ] `IMPORT-09` 同一天重复导入相同任务时会标记“可能已存在”，默认不勾选。

## 已知限制

- 浏览器内 PIN 不提供系统级安全。
- App 不能自动控制其他游戏，也不会绕过 iPad 的屏幕使用时间限制。
- IndexedDB 数据只保存在当前浏览器配置中，清理网站数据会删除记录。
- iPad 主屏幕安装和离线能力需要 HTTPS 地址或可靠的本地开发环境；正式部署方式仍需在下一阶段确认。
