# 小恐龙互动动画设计说明

参考图：[dino-animation-reference.png](./assets/dino-animation-reference.png)

## 动画使用原则

- 角色站姿、头部中心、脚底基线在所有帧中保持一致，避免播放时跳动。
- 每组动作使用 6–8 帧，单帧约 140–180ms，整段约 1–1.5 秒。
- 动作播放时暂时锁定重复操作，其他互动按钮可以被按，但不会叠加同类动画。
- 数值在动作完成时更新，同时显示 `+饱腹`、`+水分`、`+清洁`、`+心情` 小提示。
- 动作结束后统一回到待机动画，不永久停留在最后一帧。
- 尊重减少动态效果设置；关闭动画时直接切换结果画面，不阻塞功能。

## 互动动作

### 喂食

1. 发现食物
2. 走向食物
3. 低头进食
4. 享受美食
5. 吃完一半
6. 吃完大部分
7. 满足表情
8. 回到待机

### 喂水

1. 发现水源
2. 走向水碗
3. 低头喝水
4. 喝水中
5. 抬头休息
6. 满足表情
7. 水分增加提示
8. 回到待机

### 清理

1. 发现粪便
2. 走向粪便
3. 拿起清洁工具
4. 清理中
5. 清理完成
6. 抬头查看
7. 满意表情
8. 回到待机

### 抚摸

1. 发现手
2. 主动靠近
3. 被抚摸
4. 享受中
5. 开心表情
6. 心情提升
7. 轻摇尾巴
8. 回到待机

### 生病治疗

1. 生病状态
2. 发现药箱
3. 使用药品
4. 治疗中
5. 病情好转
6. 恢复中
7. 完全恢复
8. 回到待机

### 重新领养

1. 康复完成
2. 进入领养箱
3. 选择领养
4. 新的开始
5. 领养成功
6. 开启新旅程

## 生病与恢复规则

- 连续 3 天没有有效照料：进入生病状态。
- 生病后使用治疗并完成喂食、喂水和清理：进入恢复流程。
- 恢复完成后回到健康待机状态。
- 如果始终不治疗和照料，到第 6 天进入“暂时离开 / 可重新领养”结局。
- 首页不显示状态倒计时；状态通过角色动画、表情和需求面板自然呈现。

## 正式素材处理

当前图鉴用于动作顺序和角色一致性参考。实现时需要：

1. 把每组动作拆成独立透明 PNG 帧。
2. 统一画布尺寸、角色中心点和脚底基线。
3. 使用 CSS `background-position` 播放 sprite sheet，或预加载 PNG 序列。
4. 为生病、恢复、重新领养状态准备独立动画组。
5. 再制作待机呼吸、眨眼、睡觉和饥饿提示等低频循环动作。
